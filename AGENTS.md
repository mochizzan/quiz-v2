## Agent Details

### Agent 1: Directory Structure Explorer
- **Purpose**: Analyzes and documents the directory hierarchy and file organization
- **Focus Areas**: 
  - Top-level directory structure
  - File types and organization patterns
  - Entry point identification
- **Expected Deliverables**: 
  - Complete directory map
  - Key entry points documentation
  - Organizational pattern analysis

### Agent 2: Package Manifest Analyzer
- **Purpose**: Identifies project configuration and dependency management
- **Focus Areas**:
  - Package manifest files (package.json, go.mod, pyproject.toml, etc.)
  - Build systems and compilation tools
  - Dependency management and lockfiles
  - Framework fingerprinting from configuration
- **Expected Deliverables**:
  - Tech stack identification
  - Configuration analysis
  - Dependency documentation

### Agent 3: Config and Tooling Analyst
- **Purpose**: Examines development tools, testing frameworks, and CI/CD configuration
- **Focus Areas**:
  - Test structure and frameworks
  - Linting and formatting tools
  - Build and deployment tools
  - CI/CD pipeline configuration
  - Development environment setup
- **Expected Deliverables**:
  - Tooling recommendations
  - Development setup guide
  - CI/CD pipeline documentation

### Agent 4: Architecture Detective
- **Purpose**: Determines system architecture, data flow, and design patterns
- **Focus Areas**:
  - API patterns and request flow
  - Database access patterns and ORM usage
  - Error handling approaches
  - State management approaches
  - Overall architecture pattern identification
- **Expected Deliverables**:
  - Architecture documentation
  - Data flow analysis
  - Design pattern identification
